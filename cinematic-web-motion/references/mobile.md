# Mobile Cinematic Strategy

## Principle

Mobile is its own composition.

Do not merely scale desktop down.

## Consider

- viewport height
- portrait aspect ratio
- touch scrolling
- network speed
- device GPU
- memory
- browser UI affecting viewport height

## Possible adaptations

Desktop:

- long cinematic sequence
- detailed 3D
- large environment
- complex camera movement

Mobile:

- shorter sequence
- fewer frames
- simpler 3D
- reduced particles
- stronger subject framing
- static or video fallback

## Interaction

Do not require hover.

Do not depend on mouse position.

Do not make scrolling excessively heavy.

## CTA

The primary CTA should remain easy to reach and use.

A sticky mobile CTA can be appropriate for service businesses, but it should look like part of the interface rather than an advertising banner.

## Testing

Test at minimum:

- narrow phone
- large phone
- tablet
- desktop

Also test slow network conditions.
